Drop product images here (e.g. `dog-bed.jpg`).

Vite serves everything in `public/` from the site root, so an image at
`client/public/images/dog-bed.jpg` is reachable at `/images/dog-bed.jpg`
once the dev server or build is running. Use that path as a product's
`imageUrl`, e.g. `/images/dog-bed.jpg`.
